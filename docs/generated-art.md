# Painted woodland assets

Generated with the built-in image tool; no API key is shipped or required. Original transparent PNGs are bundled in public/art/v2.

Art brief: premium hand-painted woodland adventure, warm rim light, expressive dark eyes, tactile materials, readable silhouettes, transparent backgrounds, no text. Pip is a copper fox explorer with teal neckerchief; Moss a sage mossback bear-turtle with flowers and caramel scarf; Luma a lavender lantern companion with luminous golden chest star. Pip served as the style reference for both companions. Items: leaf-carved brass key and amber woodland lantern.

Creature and ObjectArt render these assets inside their existing SVG viewports, preserving responsive dimensions, celebration motion, reduced-motion behavior and accessible button labels. Other NPCs and items retain their original vector art; this is the first painted art pass.

## Cast completion pass
Nettle (fox cartographer), Hush (owl), Bramble (dragon), Puck (moth), Tock (clockkeeper), and Lyra (guardian) now have painted portraits. Apple and mushroom quest sprites match the painted key and lantern. Each was generated individually with a transparent background. Characters celebrate through motion; separate facial animation frames are not implemented.

All 13 painted assets are shipped as 640px WebP with preserved transparency, totaling about1.51MB versus21.16MB of original PNGs. Original PNGs are preserved in output/art-originals. Other simple environmental objects remain vector art.
